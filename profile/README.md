## 🌸 Sobre

Este é o meu espaço para **aprender Docker de verdade**: construindo coisas, quebrando coisas, corrigindo meus erros e compartilhando o que descubro pelo caminho.

Aqui não tem só código que deu certo. Tem também o que deu errado, por que deu errado e como eu resolvi, porque é aí que o aprendizado acontece. 💜

## 🦄 Como cada tema é documentado

Todo tema segue a mesma estrutura, para ficar fácil de acompanhar a evolução:

<div align="center">

| | Seção | Pergunta que responde |
|:-:|---|---|
| 🤔 | **O que é?** | Qual é o conceito, explicado do meu jeito |
| 💡 | **Por que existe?** | Que problema ele resolve |
| 🔨 | **Hands-on** | O que eu construí na prática |
| 💥 | **O que quebrou?** | Os erros que apareceram |
| 🛠️ | **Como resolvi?** | O passo a passo da correção |
| 🧠 | **O que aprendi?** | Os aprendizados que ficaram |
| 📚 | **Referências** | Docs, cursos e materiais usados |
